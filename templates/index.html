How it works

Five steps, from link to answers

A background job runs each step and reports progress as it goes, so the page never freezes.

  1. 01

    Download

    yt-dlp fetches the audio and splits it into 10-minute chunks.

  2. 02

    Transcribe

    Whisper turns each chunk into text on your own machine.

  3. 03

    Summarize

    Gemini writes a structured summary that scales with the video's length.

  4. 04

    Extract

    Action items, decisions, and open questions are pulled into their own lists.

  5. 05

    Index

    Everything is embedded into a local Chroma store, ready for questions.

Privacy

Your audio never leaves your machine

Downloading, transcription, and the search index all run locally. Only the transcript text is sent to Gemini to write the summary and answer questions.

  • Whisper runs on your own CPU or GPU
  • Embeddings are stored on local disk
  • Your API key stays in your own .env file

FAQ

Questions, answered

How long does an analysis take?

It depends on the video's length and your hardware. Transcription is the slowest step. A one-hour video usually takes several minutes, and the progress bar shows each chunk as it finishes.

Can I use files instead of YouTube links?

Yes. Paste the path to a local audio or video file on the machine running the server.

What do I need to run it?

Python 3.10 or newer, FFmpeg on your PATH, and a Google AI Studio API key in your .env file. The README has the full setup.

Why can't it open some videos?

Private, age-restricted, or region-locked videos can't be downloaded. The error message explains what went wrong and how to fix it.

Where do answers in the Ask tab come from?

Only from this video. The most relevant passages are retrieved from the local index, and each answer lists them as numbered sources you can expand.
